# coare-seaice

Turbulent air-sea-ice fluxes over sea ice and the marginal ice zone, as an extension of
the COARE bulk flux algorithm.

**Status: early development.** The methods documentation will be added module by module
as the code is ported and tested (see `TASKS.md` in the repository).
